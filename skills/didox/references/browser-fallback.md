# Didox.uz — карта веб-интерфейса (fallback, снято 19.08.2026)

Когда API недоступен (нет партнёрского токена, протух стенд), черновик можно
создать руками через кабинет didox.uz. Браузер — тот, где у пользователя
живая сессия Didox (логин по ЭЦП; чужой/headless профиль пуст).

## URL

| Страница | URL |
|---|---|
| Входящие | `https://didox.uz/documents/new?tab=all&page=1&limit=20` |
| Исходящие | `https://didox.uz/documents/new/outgoing?tab=all&page=1&limit=20` |
| Черновики | `https://didox.uz/documents/new/draft?tab=all&page=1&limit=20` (фильтр по ИНН: `&partner=<ИНН>`) |
| Выбор типа документа | `https://didox.uz/create_document` (кнопка «+ Создать») |
| Произвольный документ (PDF-вложение) | `https://didox.uz/document_form/000` |
| Договор (НК), структурная форма | `https://didox.uz/document_form/007` |
| Открытый документ | `https://didox.uz/documents/<ID>/1`; клик по строке в «Черновики» ведёт сразу в `/document_form/000/<ID>/edit` |
| Профиль (установка пароля) | `https://didox.uz/profile/account` |

## Типы документов (combobox «Тип документа», value → название)

`002` Счет-фактура без акта · `008` Счет-фактура (ФАРМ) · `004` ТТН ·
`023` Гибридная счет-фактура · `022` ЭСФ для СМР · `041` ТТН (новый) ·
`005` Акт · `006` Доверенность · `062` Доверенность (новая) · `007` Договор (НК) ·
`000` Произвольный документ · `052` Акт сверки · `010` Многосторонний произвольный ·
`075` Протокол собрания учредителей · `031` Письмо (НК)

## Произвольный документ (000) — что в какое поле

| Поле | Договор | Приложения к договору | Акт |
|---|---|---|---|
| Номер документа * | номер договора | `<номер договора>-1-2` | номер акта |
| Дата документа * | дата договора `дд.мм.гггг` | дата договора | дата акта |
| Номер контракта | номер договора | номер договора | номер договора |
| Дата контракта | дата договора | дата договора | дата договора |
| Название документа | «Договор возмездного оказания услуг № N от дд.мм.гггг» | «Приложения № 1 и № 2 к Договору … № N от …» | «Акт № … к Договору № N от …» |
| Подтип документа | **Договор** | **Доп. соглашение** | **Акт выполненных работ** |
| ИНН/ПИНФЛ партнёра * | ИНН из реквизитов | тот же | тот же |
| Файл | PDF договора | PDF приложений | PDF акта |

Подтипы в выпадающем списке: Акт сверки, Письмо, Договор, Счет на оплату,
Акт выполненных работ, Другое, Заявка, Спецификация, Доп. соглашение,
Акт приема-передачи, Акт о начислении штрафа, Перевод долга, Предоплата.

Ограничение вложения: `.pdf`, не более 10 МБ, один файл на документ.

## Ввод в поля (грабли)

- Текстовые поля: клик по полю → ввод текста. Программная установка value у
  React-полей не всегда триггерит state — не полагаться на неё для номера/названия.
- Даты: клик → ввод `дд.мм.гггг` → `Escape` (закрыть датапикер), иначе
  следующий клик попадёт в календарь.
- ИНН партнёра: после ввода подождать 2–3 с — Didox подтянет наименование и
  адрес из базы. Сверить с реквизитами договора; не совпало — стоп.
- Подтип: раскрыть список кликом → выбрать пункт по его элементу, не по
  координатам (клик по координатам выбор не применяет).
- Файл: загружать напрямую в `input[type=file]`, НЕ кликать по зоне
  «Перетащите файл сюда» — откроется нативный диалог, из которого не выбраться.
- Кнопки внизу: «Показать документ» (превью), «Сохранить» (черновик),
  «Подписать» (E-IMZO — только пользователь), «Отменить».

## Роуминг

После «Сохранить» для типа `000` всплывает модалка: «Данный тип документа не
синхронизируется с сервисами Роумингового оператора (май солик) и доступен
для подписания только на сервисах "Didox"». Смысл: произвольный документ
увидит только контрагент, зарегистрированный в Didox. Если контрагент у
другого оператора ЭДО (Faktura.uz, E-Hujjat…) — подавать договором типа `007`
(структурная форма с ИКПУ, без PDF). Где сидит контрагент — знает пользователь
или бухгалтер контрагента.

## Проверка черновика

Вкладка «Черновики»: строка показывает тип (`Произвольный документ (исх.)` +
подтип жирным), контрагента с ИНН, «Номер и дата документа», «Номер и дата
договора». Клик по черновику открывает сразу форму редактирования — кнопки
«Редактировать» нет, это норма.
